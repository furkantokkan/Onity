# Measurement history

Use this section when you need the earlier measurements, experiments and release snapshots that the
current pages no longer carry. The current results, with their conditions, are on the
[Comparisons](../comparisons/index.html) pages; the raw records are under `docs/benchmarks/` and
`docs/assets/benchmarks/` in the repository.

Rules for every page here:

- The text was moved as it was, on the date each page states. It keeps its original Unity version,
  source revision, wording and links, so a statement describes the state at its date, not the current
  release.
- Only links whose relative path changed with the move were edited; nothing was reworded.
- Newer measurements supersede these pages. When a page here and a comparison page disagree, the
  comparison page is current.

Pages:

- [OnityTask measurement history](onitytask-comparison-history.html): the dated OnityTask and UniTask
  measurements and experiments that preceded the 2026-10-02 Release Player gate.
- [DI and pooling measurement history](di-benchmark-history.html): the DI, pooling and release
  snapshots moved out of the README files, the home page, the performance guide and the architecture
  page.
